# Customer Churn Analysis

## Project Overview

This project analyses customer churn in a telecommunications dataset to identify customer groups that are more likely to leave the service.

## Tools Used

* Python
* Pandas
* Matplotlib
* SQL Server
* SQL Server Management Studio (SSMS)
* Microsoft Power BI

## Dataset

* Total customer records: 7,043
* Total columns: 21
* Industry: Telecommunications

## Project Workflow

1. Explored the dataset using Python and Pandas.
2. Analysed customer churn patterns.
3. Stored the dataset in SQL Server.
4. Connected SQL Server to Power BI.
5. Created an interactive dashboard with charts and slicers.

## Key Findings

* Overall churn rate: 26.54%.
* Month-to-month customers showed higher churn than customers on longer-term contracts.
* Customers who left had lower average tenure.
* Customers who left had higher average monthly charges.
* Electronic check users and fiber-optic internet customers showed relatively high churn.

## Business Recommendations

* Explore incentives for longer-term contracts.
* Investigate pricing concerns among customers with higher monthly charges.
* Monitor new customers who may be at risk of leaving.
* Review customer feedback related to payment methods and internet services.

## Dashboard

The dashboard includes churn rate by contract type, payment method, and internet service, along with average monthly charges, average tenure, and an overall churn-rate card. Interactive slicers allow customer segments to be explored.
